EWMA/双窗口自适应 Teacher Refresh 验证计划

本计划只定义方法与实验方案，暂不执行训练。目标是在 GRPO+SDPO/OPSD 中，用更稳健的指标触发一次 teacher refresh： 不再指定固定 step，也不把 warmup=80 作为硬门槛，而是通过 EWMA、短/长双窗口、连续满足条件、KL 与失败率保护来判断 student 是否已经足够稳定，随后只同步一次 teacher，并明确记录 refresh step。

模型：Qwen3-VL-4B 训练：rs_train 全量 方法：GRPO + SDPO/OPSD 首验：zoom_in 更新：teacher only，ref 不动 日期：2026-05-24

核心判断

当前的 metric refresh 已经比固定 step 更合理，但它主要依赖一个 rolling window 相对早期 baseline 的提升。 这个做法能减少单步噪声，但仍存在两个问题：早期 baseline 偏低会过早刷新，早期 baseline 偏高会迟迟不刷新； 同时它没有要求指标连续满足，容易被一次窗口波动触发。

新方案把 teacher refresh 看成“当 student 的近期能力稳定超过长期基线，且没有明显发散时，同步 teacher 一次”。 因此触发条件必须同时回答三个问题：student 是否稳定变强、失败率是否可控、相对 ref 的 KL 是否仍在安全范围。

信号定义

不增加额外验证集 probe，不增加额外模型前向，直接复用训练中已有的 rollout/SDPO/GRPO 标量。

信号 含义 用途 风险点
sdpo_iou_mean 当前 rollout bbox 与 GT 的平均 IoU 主触发指标，判断 student 定位质量是否提升 单步噪声较大，必须平滑
sdpo_iou_at_05 rollout 中 IoU 超过 0.5 的比例 辅助判断可用 bbox 的比例是否提升 可能对高精度定位不敏感
sdpo_route_failed 低于失败阈值的 rollout 比例 失败率保护，防止把不稳定 student 同步给 teacher 阈值过严可能不触发
sdpo_loss SDPO teacher 分布指导仍产生的 loss 判断 teacher 仍有训练信号，避免 teacher/student 已接近时无意义刷新 不能单独作为质量指标
kl student 相对 ref model 的 KL 发散保护，KL 过高不允许 refresh 过严会阻止有效更新

EWMA 与双窗口

每个训练 step 汇总多卡平均后的指标后，维护三类统计：

  • EWMA：指数滑动平均，快速吸收趋势，但不过度相信单步波动。
  • short_window：短窗口均值，例如最近 20 个记录点，表示 student 的近期状态。
  • long_window：长窗口均值，例如最近 80 个记录点，表示更平稳的训练背景状态。
ewma_t = alpha * metric_t + (1 - alpha) * ewma_{t-1}
short_mean = mean(metric[t - short_window + 1 : t])
long_mean  = mean(metric[t - long_window + 1 : t])

首版建议不设固定 step80 warmup，但仍要求 long_window 攒满后才允许触发。 这等价于“从 0 step 开始监控”，但不会在前几个极不稳定 step 因偶然高分而同步 teacher。

触发规则

只刷新一次。满足以下条件时，把当前 student 参数同步给 teacher；ref model 保持 base 不变。

ready =
  teacher_not_refreshed
  and records >= long_window

quality_gain =
  short_iou_mean >= long_iou_mean + min_short_long_iou_gain
  and ewma_iou_mean >= baseline_ewma_iou_mean + min_ewma_iou_gain
  and short_iou_at_05 >= long_iou_at_05 - max_iou05_drop

stability_guard =
  short_route_failed <= max_failed_ratio
  and short_kl <= max_kl_to_ref
  and short_sdpo_loss >= min_sdpo_loss

consecutive_guard =
  quality_gain and stability_guard 连续满足 N 次检查

if ready and consecutive_guard:
  refresh teacher from student once
  record refresh_step, refresh_reason, short/long/EWMA metrics

相比当前单窗口方案，关键变化是：

  • 不是只和最早 baseline 比，而是同时看近期短窗口是否超过长窗口。
  • 不是一次满足就触发，而是连续满足 N 次检查才触发。
  • KL 和失败率是硬保护条件，任何一个不满足都重置连续计数。
  • 触发后立即关闭监控，不再更新第二次 teacher。

建议参数

参数 建议值 解释
short_window 20 反映最近训练状态，比 50 更敏感。
long_window 80 提供稳定背景线；不是固定 80 step 更新，只是统计窗口长度。
ewma_alpha 0.10 对近期趋势有响应，但不会被单个 batch 主导。
check_interval 10 每 10 step 判断一次，开销可以忽略。
consecutive_checks 2 连续两次满足才 refresh，减少偶然触发。
min_short_long_iou_gain 0.006 短窗口 mIoU 至少比长窗口高 0.6 个点。
min_ewma_iou_gain 0.008 EWMA 相比初始 EWMA baseline 至少高 0.8 个点。
max_iou05_drop 0.010 允许 mIoU 提升时 IoU@0.5 有轻微波动，但不能明显掉。
max_failed_ratio 0.55 沿用当前经验阈值，失败率太高说明 student 不稳。
max_kl_to_ref 0.30 沿用当前 KL 保护，防止同步偏离 ref 太远的 student。
min_sdpo_loss 0.02 teacher 仍应提供有效分布指导，loss 太低则刷新收益有限。

记录与可解释性

本方法必须把触发时刻记录清楚，否则无法解释为什么某次实验有效或无效。

  • 日志打印：SDPO teacher refreshed from student at global_step=...。
  • 训练 metrics 记录：sdpo/teacher_refreshed=1、sdpo/teacher_refresh_step。
  • 触发原因记录：short_iou_mean、long_iou_mean、ewma_iou_mean、route_failed、kl、sdpo_loss、连续满足次数。
  • 如果训练结束仍未触发，也要记录 teacher_refresh_step=-1 和最后一次检查的失败原因。

先只验证 zoom_in，因为现有消融显示 zoom_in 在 bbox 定位上更有潜力，同时避免并发过多实验污染资源判断。

实验 配置 对照对象 评价指标

成功标准

实现成功：训练日志明确出现 refresh step，或者明确记录未触发原因；触发后训练继续跑完并保存 checkpoint-870。

实验成功：相比 R08 metric-trigger zoom_in，至少提升 mIoU 或 IoU@0.6/0.7/0.8 中两个指标，且 IoU@0.5 不明显下降。

风险与备选

风险 表现 处理
过早触发 刚攒满 long_window 后立刻 refresh，后续性能不升反降 提高 consecutive_checks 到 3，或提高 min_ewma_iou_gain。
不触发 训练结束 teacher_refresh_step=-1 降低 min_short_long_iou_gain 或 min_ewma_iou_gain，但保留 KL/失败率保护。
触发后 teacher 变弱 训练 loss 或 rollout 指标明显变差 增加 max_iou05_drop 保护，要求 IoU@0.5 不低于长窗口。
指标噪声跨卡不一致 不同 rank 判断不一致 所有指标先 all-reduce 后只由 rank0 计算决策，再 broadcast refresh decision。
