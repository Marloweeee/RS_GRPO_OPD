基于训练指标的一次性动态 Teacher Refresh 验证计划

本计划验证一种比固定 step80 更自适应的 SDPO teacher 更新策略： 训练过程中不预设具体刷新步数，而是在 warmup 之后观察 student rollout 的定位质量、 失败比例、SDPO 分布纠偏强度与 GRPO KL，当指标显示 student 已经稳定强于早期状态且 teacher 可能过时时， 将当前 student 参数同步给 teacher 一次；同步后关闭刷新监控，ref model 保持不变。

任务：遥感 bbox grounding 训练：Qwen3-VL-4B 全量 rs_train 方法：GRPO + SDPO/OPSD 刷新：指标触发，仅一次 日期：2026-05-23

1. 动机

固定 step80 刷新 teacher 的策略已经验证了一个重要事实： 不重启训练、不重新加载 checkpoint，而是在训练进程内把 student 权重同步给 SDPO teacher 是可行的。 但是固定步数仍然依赖经验估计，不同提示模式、不同 batch 设置、不同数据混合方式下，student 变强的时机并不一定一致。

因此更合理的第一版方案是：不做额外 probe，不增加生成开销，只利用训练过程中已经计算出的标量指标， 自动判断是否刷新 teacher。这样资源消耗几乎不变，并且触发后立即停止监控逻辑。

2. 方法定义

新增一种 sdpo_teacher_refresh_mode=metric 模式，与已有固定步数模式兼容。

模式 含义 用途
fixed 沿用 sdpo_teacher_refresh_step，到指定 step 后刷新一次。 复现实验与固定 step80 对照。
metric warmup 后根据 rolling window 指标触发一次 teacher refresh。 本次验证的动态刷新策略。
off 不刷新 teacher。 保留为消融或排错入口。

动态刷新只更新 teacher，不更新 ref：

student: 持续训练，并同步到 vLLM 做 on-policy rollout
teacher: base 初始化，满足指标后 student -> teacher 同步一次
ref:     base 初始化，全程不变，继续作为 GRPO KL anchor

3. 触发指标

第一版不引入额外模型前向或小型 probe set，只使用训练已有信号：

指标 来源 作用
sdpo/iou_mean rollout bbox 与 GT 的 IoU 判断 student 当前定位质量是否已超过早期基线。
sdpo/iou@0.5 rollout bbox 成功率 避免只靠 mIoU 波动触发，辅助确认定位成功率稳定。
sdpo/route_failed SDPO 路由 失败比例太高说明 student 仍不稳定，不应污染 teacher。
sdpo/loss teacher top-k KL 蒸馏损失 当 student 已经变强但 SDPO loss 仍偏高时，说明 teacher 可能滞后。
kl GRPO 相对 ref 的 KL 防止 student 偏离 ref 过大时同步 teacher。

4. 触发规则

设 rolling window 为最近 W 个记录点。先用早期窗口建立 student 初始基线，然后 warmup 后每隔若干 step 检查一次。

允许刷新，当且仅当：

step >= warmup_step
and teacher 尚未刷新
and rolling_iou_mean >= baseline_iou_mean + min_iou_improve
and rolling_route_failed <= max_failed_ratio
and rolling_sdpo_loss >= min_sdpo_loss
and rolling_kl <= max_kl_to_ref

建议第一组参数：

参数 建议值 理由
warmup_step 80 延续固定 step80 的经验，但不强制在 80 更新。
window 50 平滑 rollout 组内波动，避免单步高 IoU 误触发。
check_interval 10 降低判断频率，开销可以忽略。
min_iou_improve 0.01 第一版偏保守，确保能观察动态触发是否工作。
max_failed_ratio 0.55 失败比例过高时不刷新，避免 teacher 被不稳定 student 污染。
min_sdpo_loss 0.02 SDPO loss 太低说明 teacher 与 student 已较接近，刷新收益有限。
max_kl_to_ref 0.30 student 对 ref 偏离过大时不刷新，保持稳定性。

5. 实验矩阵

实验 OPSD hint/mask Teacher refresh 目的
动态刷新 + gaussian gaussian metric，仅一次 与默认高斯 SDPO 逻辑对齐，观察动态刷新能否优于固定 step 或无刷新。
动态刷新 + zoom_in zoom_in metric，仅一次 验证当前更有潜力的 zoom-in 提示模式是否从动态 teacher 中进一步受益。

两组均使用 Qwen3-VL-4B base、全量 rs_train.jsonl、两机并行、save_steps=10、 训练结束后再独立评测 IoU@0.5 到 IoU@0.9。

6. 成功标准

实现层面成功：日志出现动态触发原因、刷新 step、copied=713，并且训练继续跨过刷新点。

实验层面成功：最终全量测试集 mIoU 或 IoU@0.6/0.7/0.8 相比固定 step80 或普通 GRPO+SDPO 有提升，且没有明显降低 IoU@0.5。

7. 风险与排查

风险 表现 处理
指标过严导致不触发 训练结束日志中没有 refresh 降低 min_iou_improve 或 min_sdpo_loss，但保持只刷新一次。
指标过松导致过早触发 刚过 warmup 立刻刷新，性能无提升 提高 window 或 min_iou_improve。
student 发散时刷新 刷新后 loss/kl 波动变大 降低 max_kl_to_ref 或降低 max_failed_ratio。
