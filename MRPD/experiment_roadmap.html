已形成的主线：SFT 先稳定 bbox 输出格式与基础语义定位；GRPO 通过组内相对优势提升好轨迹概率；OPSD/MRPD 用视觉提示教师纠偏低质量轨迹；教师刷新/EMA 决定教师指导是否滞后。当前 test 结果表明，SFT 后继续 GRPO 或 MRPD 都能明显超过 SFT-only。

下一步最重要的缺口：当前主方法相对 GRPO-only 的提升幅度较小，因此论文必须补齐多 seed、paired bootstrap、pass@8 gap reduction、teacher-route 机制分析。否则方法容易被质疑为“GRPO 已经足够，OPSD/MRPD 只是工程堆叠”。

1. 论文实验组织方式

主实验：证明有效 P0：投稿前必须补齐 P1：机制与稳健性 P2：泛化、成本与边界

建议论文 claim

MRPD 是面向遥感 grounding 的多轨迹相对偏好学习框架：它利用 rollout 组内的相对优势学习“选择更好 bbox”的策略，并用视觉提示增强教师对低质量轨迹进行选择性纠偏，从而把 best-of-N oracle 中暴露出的定位上限转化为单次 greedy 推理能力。

实验必须构成四层证据

  • 主结果层：SFT-only、GRPO-only、OPSD-only、GRPO+OPSD/MRPD 在同一 test split 上公平比较。
  • 组件因果层：证明 GRPO、OPSD、hint、teacher refresh、EMA、路由阈值分别对应明确作用，而不是任意组合。
  • 机制解释层：证明 best@8 gap 真实存在，MRPD 缩小了 gap；证明 teacher 在 failed route 上更强。
  • 可信度层：多 seed、bootstrap 显著性、跨数据集、数据泄漏检查、成本与失败案例。

6. 建议执行顺序

最优先顺序：先做不需要 GPU 的统计与数据检查，再补最能增强论文可信度的 GPU 实验。不要先跑大量新超参，先把现有强结果变成可被审稿人相信的证据。

  1. CPU 任务：RSVG-DIOR image-level split 检查；整理主表；准备 paired bootstrap 所需 per-sample IoU。
  2. 评测任务：GRPO-only 与 MRPD EMA/metric 的 pass@8，补 best-of-8 gap reduction。
  3. 训练任务：MRPD metric refresh 与 EMA0.98 的额外 seeds；必要时补 GRPO-only seed。
  4. 机制任务：route/teacher gap 统计，failed route 中 teacher 是否优于 student。
  5. 泛化任务：等待 RSVG-DIOR MRPD 完成；补 RSVG-DIOR GRPO-only。
  6. 附录任务：rollout N、OPSD 阈值、hint 强度、KL/beta、成本和失败案例。

7. 每个实验必须记录的字段

  • 训练配置：base model、SFT ckpt、teacher ckpt、ref ckpt、train/val/test jsonl、epoch、max_steps、batch size、gradient accumulation、num_generations、learning rate、warmup、beta、temperature、top_p、top_k。
  • MRPD/OPSD 配置：hint mode、mask mode、tau_good、tau_fail、only_failed、OPSD loss weight、teacher refresh mode、refresh step、EMA decay、是否同步 ref。
  • 指标：mIoU、IoU@0.5/0.6/0.7/0.8/0.9、parse_rate、valid_rate、best@8、first@8、gap reduction、route 比例、KL、reward。
  • 可靠性：seed、mean±std、paired bootstrap CI、p-value、是否有异常重启或保存失败。
  • 产物路径：checkpoint、training log、eval summary、per-sample result、可视化目录、rjob 名称和运行资源。
